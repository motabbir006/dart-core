# Dart for Flutter Developers 🚀

A curated collection of **Dart problem-solving exercises** designed specifically to build a **strong foundation for Flutter development**.

This repository focuses on **logic, core Dart concepts, and real-world problem patterns** that are commonly used in Flutter apps and technical interviews.

---

## 📌 Why This Repository?

Flutter depends heavily on **Dart fundamentals**.  
Before jumping into widgets and UI, mastering Dart logic is essential.

This repo helps you:
- ✅ Think like a Flutter developer
- ✅ Improve problem-solving skills
- ✅ Understand Dart deeply (not just syntax)
- ✅ Prepare for Flutter interviews

---

## 🧠 Topics Covered

### 🔹 Core Dart Basics
- Variables & Data Types
- Conditional Statements (`if`, `else`, `switch`)
- Loops (`for`, `while`, `do-while`)
- Functions & Methods

### 🔹 Collections
- List
- Set
- Map
- Iteration techniques

### 🔹 OOP in Dart
- Class & Object
- Constructor
- Inheritance
- Encapsulation
- Polymorphism
- Abstraction

### 🔹 Null Safety
- Nullable vs Non-nullable
- `?`, `!`, `late`
- Common null-safety mistakes

### 🔹 Asynchronous Programming
- `Future`
- `async` / `await`
- `then`
- Error handling

### 🔹 Logic & Algorithm Practice
- Number problems
- String manipulation
- Pattern printing
- Logical thinking problems
